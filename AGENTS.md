# BULLIS Development Guidelines

## Project Overview
BULLIS is a research-grade commodity derivatives intelligence platform focusing on MCX gold futures analytics, anomaly DNA, edge simulation, and risk radar.

## Rules & Standards
- Keep commit history clean and meaningful.
- Ensure all tests pass (`npm run test`) and code builds cleanly (`npm run build`) before pushing.
- Maintain typed interfaces and clean architecture across TanStack Router and components.
